## API Routes

### GET /api/wiki
Returns list of wiki pages.

### GET /api/wiki/:id
Returns full page.

### POST /api/wiki
Creates new page.

### PUT /api/wiki/:id
Updates an existing page.

Markdown/HTML content is supported.
