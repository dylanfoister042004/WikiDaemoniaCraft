# DaemoniaCraft — Production UI  
Dark-fantasy Solo Leveling inspired website with a full Wiki system.

Tech stack:
- Vite + React + TypeScript  
- TailwindCSS  
- TipTap Rich Text Editor  
- React Router  
- Placeholder backend (Firebase-ready)  

Run:
npm install git add package-lock.json git commit -m "Add package-lock.json for CI" git push
- npm run dev

Build:
- npm build
